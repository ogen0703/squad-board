# サッカー部 スカッドボード

A・Bチームのメンバー表(スタメン/サブ)と、フォーメーション上で選手を並べて交代を記録できるWebアプリ(PWA)。

- スマホのホーム画面に追加すると、アプリのように全画面で起動します
- データはその端末の中に保存されます(別の端末へは「部員の登録」→「データの書き出し・読み込み」)
- オフラインでも使えます

## できること(v2 で追加)
- 次の試合(日付・相手・試合時間)と出欠(参加/未定/不参加)。不参加の人はスカッドから外れる
- スタメン案を名前つきで保存・呼び出し
- 画像で共有(フォーメーションとサブを1枚の画像にして、LINEなどへ)
- 試合タイマー(前半・ハーフタイム・後半)。交代・得点の「分」が自動で入る
- 得点(アシスト)・失点・カードの記録、スコア、出場時間、ベンチの「未出場」の印
- 記録に保存 → 「試合記録」タブで試合の一覧・成績・個人成績(試合・先発・出場時間・得点・アシスト・警告)
- 5人制(フットサル)のフォーメーション
- 紅白戦のチーム分け(ポジションのバランスを見て2チームに)
- 戦術ボードの作戦を名前つきで保存
- 書き出しから14日たつとお知らせ(書き出しには試合記録・スタメン案・作戦も入る)
